#
#   * an `--extra-index-url` on a pinned CUDA version silently resolves to the

#   * the default PyPI torch wheel for **Windows** is CPU-only.
#
# The result was a silent CPU-only install: `torch 2.12.1+cpu`, and then
# unsloth failing with "Unsloth cannot find any torch accelerator? You need a
# GPU." on a machine that had a GPU. Do not re-add torch here.
#
# Everything below is pure-Python or resolves identically on either wheel.
